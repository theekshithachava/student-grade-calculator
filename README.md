Student Grade Calculator

This project is a simple Python program that accepts the marks of a student in multiple subjects. It calculates the total and average marks, assigns a grade based on the average, and displays whether the student has passed or failed.

Features

- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average marks
- Assigns a grade
- Displays pass or fail status

Technologies Used

- Python

Project Purpose

The main purpose of this project is to practice Python programming concepts such as user input, loops, calculations, and conditional statements.

How to Run

1. Clone or download the repository.
2. Open the Python file in VS Code or any Python editor.
3. Run the program.
4. Enter the marks when prompted.
5. The program will display the total, average, grade, and pass/fail result.

 
Learning Outcome


This project helped me understand Python basics such as variables, loops, user input, arithmetic operations, and if-else conditions.
